# ZY's ActiveSG Filter

Singapore's ActiveSG Programmes filter based on my personal use case.

## Description

This app searches for ActiveSG programmes based on 2 things:

Weekends + Location

### Technology Used

Technologies used to build this project.

```
- React
- Axios
- date-fns
```
